# 16. Glossary

> Từ điển domain + technical terms. Chỉ các concept thực sự tồn tại trong code.
> Mục tiêu: tránh nhầm các khái niệm giống nhau.

---

| Thuật ngữ                            | Định nghĩa                                                                                      | Quan hệ                                                                                                   | Code/DB representation                                                 |
| ------------------------------------ | ----------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Flashcard**                        | Đơn vị học: cặp front/back.                                                                     | Thuộc đúng một bộ thường; có thể nằm trong nhiều bộ đặc biệt; có thể xuất hiện trong nhiều quiz snapshot. | Bảng `flashcards` (`front`, `back`, `position`).                       |
| **Regular set** (bộ thường)          | Bộ flashcard từ import hoặc tạo thủ công; thẻ gốc thuộc bộ này.                                 | Sở hữu flashcards (1–n).                                                                                  | Bảng `flashcard_sets`.                                                 |
| **Special collection** (bộ đặc biệt) | Bộ gom thẻ từ nhiều bộ thường; không sao chép nội dung, chỉ lưu membership.                     | Membership với flashcards (n–n).                                                                          | Bảng `special_collections` + `special_collection_items`.               |
| **Membership**                       | Quan hệ thẻ ↔ bộ đặc biệt.                                                                      | —                                                                                                         | `special_collection_items` (PK collection+card).                       |
| **Study session**                    | Phiên học flashcard (lật thẻ), không lưu DB.                                                    | Dùng source từ sets/collections.                                                                          | `/study/session`; state trong client + query.                          |
| **Quiz**                             | Bài test trắc nghiệm từ nguồn đã chọn.                                                          | Sinh `quiz_sessions` + `quiz_questions`; hoàn thành → stats/streak.                                       | RPC `create_quiz_session`, `submit_quiz_answer`.                       |
| **Quiz session**                     | Một lần làm bài (snapshot source + kết quả).                                                    | Chứa nhiều `quiz_questions`; có `origin`; tham gia coverage nếu `manual`.                                 | Bảng `quiz_sessions`.                                                  |
| **Quiz question**                    | Một câu hỏi snapshot: prompt, đáp án đúng, 4 choices, đáp án chọn, is_correct.                  | Thuộc một session; link `flashcard_id` (SET NULL) + `source_flashcard_id` (durable).                      | Bảng `quiz_questions`.                                                 |
| **Attempt**                          | (Từ AGENTS.md) — không tồn tại trong implementation; thay bằng quiz session.                    | —                                                                                                         | —                                                                      |
| **Snapshot**                         | Bản sao dữ liệu câu hỏi tại thời điểm tạo quiz; không đổi khi sửa thẻ.                          | —                                                                                                         | `quiz_questions` columns (prompt/correct_answer/choices).              |
| **Source scope**                     | Phạm vi chọn nguồn: tất cả / các set / các collection.                                          | —                                                                                                         | `quiz_sessions.source_set_ids`, `source_collection_ids`, `source_all`. |
| **Quiz origin**                      | Loại phiên: `manual` (người dùng tự chọn) hoặc `smart_review` (server chọn thẻ due). Immutable. | Chỉ `manual` tạo coverage quiz.                                                                           | Column `quiz_sessions.origin` + trigger.                               |
| **Mode (quiz)**                      | Chiến lược chọn thẻ: `balanced`, `never_tested`, `wrong_answers`, `pure_random`.                | `never_tested`/`wrong_answers` strict pool; `balanced` giữ internal ordering.                             | Column `quiz_sessions.mode`; union `QuizMode` trong TS.                |
| **Filter (learning modes)**          | Bộ 3 filter UI: `unseen`/`wrong`/`random`. Map sang quiz mode.                                  | —                                                                                                         | `src/features/learning-modes/types.ts`.                                |
| **Strict pool**                      | Pool chỉ chứa thẻ đúng tiêu chí filter; không backfill.                                         | —                                                                                                         | migration 20260813000000.                                              |
| **Distractor**                       | Đáp án nhiễu (3) cho mỗi câu; không trùng sau normalize.                                        | —                                                                                                         | Sinh trong `create_quiz_session`.                                      |
| **Coverage**                         | Trạng thái "thẻ đã làm trong cycle hiện tại" theo mode (quiz/match/memory/runner).              | Nguồn filter "Chưa làm".                                                                                  | Bảng `flashcard_coverage` (user, mode, card).                          |
| **Coverage session**                 | Snapshot server-created (session/scope card ids) để completion idempotent.                      | —                                                                                                         | Bảng `learning_coverage_sessions`; RPC create/complete.                |
| **Coverage reset**                   | Khi scope đã cover toàn bộ → xóa coverage của scope (bắt đầu cycle mới).                        | —                                                                                                         | `complete_learning_coverage_session` (`did_reset`).                    |
| **Review event**                     | Sự kiện ôn tập bất biến của một thẻ (nguồn: quiz, study_recall, typing, cloze, smart_review).   | Nguồn sự thật của FSRS projection + mastery.                                                              | Bảng `card_review_events`.                                             |
| **FSRS rating**                      | 1=Again, 2=Hard, 3=Good, 4=Easy. Quiz map: sai→Again(1), đúng→Good(3).                          | —                                                                                                         | Column `card_review_events.fsrs_rating`.                               |
| **Schedule (projection)**            | Trạng thái FSRS của thẻ (state, stability, difficulty, due…) — rebuildable từ events.           | —                                                                                                         | Bảng `card_learning_schedule`.                                         |
| **Projection revision**              | Version optimistic concurrency của schedule.                                                    | —                                                                                                         | Column `projection_revision` + CAS RPC.                                |
| **Frozen config / parameter_set**    | Cấu hình FSRS cố định (`flashlearn-v1`) — đổi tham số phải đổi id.                              | —                                                                                                         | `src/features/spaced-repetition/config.ts`.                            |
| **Due card**                         | Thẻ có `due <= now` trong schedule (cần ôn).                                                    | Nguồn Smart Review.                                                                                       | `card_learning_schedule.due`.                                          |
| **New card**                         | Thẻ chưa từng học: không schedule + không event schedulable.                                    | —                                                                                                         | RPC `load_new_card_candidates`.                                        |
| **Smart Review**                     | Phiên ôn thẻ due (batch 10), chạy dưới dạng quiz origin `smart_review`.                         | —                                                                                                         | `src/features/smart-review/`.                                          |
| **Mastery**                          | Mức thành thạo thẻ derived từ review history (untested/review/learning/strong).                 | —                                                                                                         | `src/features/mastery/` + visual tokens `--mastery-*`.                 |
| **Streak**                           | Chuỗi ngày liên tiếp có ≥1 quiz hoàn thành, tính theo local date.                               | —                                                                                                         | `daily_learning_records` + RPC `get_learning_statistics`.              |
| **Local activity date**              | Ngày địa phương (theo timezone profile) của một hoạt động hoàn thành.                           | —                                                                                                         | `daily_learning_records.local_date`.                                   |
| **Match**                            | Trò chơi ghép cặp front/back; coverage mode `match`.                                            | —                                                                                                         | `src/features/match/`.                                                 |
| **Memory**                           | Trò chơi lật ô nhớ; coverage mode `memory`.                                                     | —                                                                                                         | `src/features/memory/`.                                                |
| **Eligibility (availability)**       | Số thẻ hợp lệ cho một lựa chọn (source + filter + số câu).                                      | —                                                                                                         | `getQuizEligibility`, `getMatchAvailability`, `getMemoryAvailability`. |
| **Wrong-answer history**             | Tập thẻ từng trả lời sai trong quiz completed (canonical shared).                               | Nguồn filter "Câu sai" mọi mode.                                                                          | `loadWrongAnswerCardIds` (đọc `quiz_questions`).                       |
| **Server action**                    | Hàm `"use server"` nhận input từ client, validate, gọi DB/RPC.                                  | —                                                                                                         | `src/features/*/server/actions.ts`.                                    |
| **Admin client**                     | Supabase client dùng service role key (server-only).                                            | —                                                                                                         | `src/lib/supabase/admin.ts`.                                           |

## Những cặp dễ nhầm

| Nhầm lẫn                                                   | Phân biệt                                                                                               |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Quiz session vs Study session                              | Quiz: trắc nghiệm, lưu DB, tính streak. Study: lật thẻ, không lưu DB.                                   |
| Quiz mode (`never_tested`…) vs Learning filter (`unseen`…) | Filter là UI, map sang mode qua `learningFilterToQuizMode`; `balanced` không còn trong UI.              |
| `flashcard_id` vs `source_flashcard_id`                    | `flashcard_id` link sống (SET NULL khi xóa thẻ); `source_flashcard_id` identity durable cho lịch sử.    |
| Review event vs Schedule                                   | Event = sự thật bất biến; schedule = projection rebuildable.                                            |
| Coverage vs Wrong-answer history                           | Coverage: thẻ đã làm cycle này (per mode); wrong history: thẻ từng sai (shared, từ quiz).               |
| `requested_question_count` vs `actual_question_count`      | Luôn bằng nhau (strict) — không có backfill.                                                            |
| Collection vs Set                                          | Set = bộ thẻ gốc; collection = bộ gom membership (không sao chép nội dung).                             |
| `unseen` filter vs `never_tested` mode                     | Cùng ý nghĩa "chưa cover/kiểm tra"; `unseen` dùng coverage per mode, `never_tested` dùng quiz coverage. |
